# A-Level Physics Course

Unified AQA A-level Physics 7408 course app assembled from the existing topic repositories.

Core topic order follows the AQA specification:
1. Measurements and their errors
2. Particles and radiation
3. Waves
4. Mechanics and materials
5. Electricity
6. Further mechanics and thermal physics
7. Fields and their consequences
8. Nuclear physics

This repository is being used as the single course shell so students can move through the full AQA core in specification order while retaining the detailed lessons, textbook content, simulations, formula support, practical work and assessment tools from the individual topic apps.
